关于 Aivaro 与收录规范

这一页按五个部分说明本站：它是什么、数据从哪来、名单怎么形成、发现错误怎么纠正、以及我们对使用者的声明。方法公开，结论才可核对。

一、站点说明

Aivaro 是一个独立维护的 AI API 服务导航站，做三件事：发现（把分散的中转与聚合服务整理成一份可检索的名单）、比较（把同一模型的公示单价放到同一口径下对照）、导航（把你送到服务商官网，交易与使用都在那边发生）。

本站不提供中转服务、不发售 API Key、不经手资金、不收集任何第三方账号凭据。本站页面包括：首页、服务目录、服务详情、价格对比、免费额度专题、投稿收录、广告合作与本页；没有账号体系，不需要注册登录。本站与被收录的任何服务商都没有运营、代理或隶属关系。

二、数据来源

信息来源政策

  • 本站数据全部由维护者从服务商官方页面逐条查阅整理。来源优先级：①官网定价页 / 模型页；②官方文档；③官方公告（博客、状态页、官方社群公告）。三者之外一律不作为数据来源；
  • 其他导航站、店铺页、社群帖子与口头信息，最多只能作为「待核实线索」，不会被写成事实；本站也不从任何同行站点搬运数据；
  • 每条价格、额度与状态信息都在详情页给出源链接与核实日期；查不到的字段直接标「待核实」，不推测、不拿别家数据填充。

核实节奏与过期规则

  • 价格与免费额度：每 30 天逐条复核；服务状态：每 14 天快速巡检；新收录的服务在第 7 天做一次早期复核；
  • 超过应核实日期未复核的条目自动标「待复核」；超期两倍标「可能过期」，并在目录与比价排序中降权；
  • 免费额度政策若经复核确认已取消，条目标记「已失效」但保留展示——本站统计只说「最近一次复核未发现取消」，不说「可用」，因为我们无法替服务商承诺政策存续；
  • 每次核实都记入详情页的「核实记录」时间线，字段变更留痕。

状态与排序的口径

本站状态（如「官网可打开」）来自核实日的人工访问结论，不是可用性百分比，也不代表 API 网关实时可用、模型真实或计费准确。部分同行会做无凭证自动探测并披露样本量，那是他们的方法；在我们拥有持续探测样本之前，不发布此类数字。

  • 目录默认「综合」排序分三步：先把状态异常的条目整体放到最后；其余先比核实完整度（核心字段里核实到的项数），再比谁的支付方式更多、谁覆盖的模型厂商更广；仍相同的，按名称先后。本站暂无可靠的运营时长数据，故以核实完整度代偿该维度，代偿规则在此公开，不做隐藏加权；
  • 可切换的价格、最近核实、名称排序为本站附加功能；比价页默认按所选价格列升序、最低价高亮，未公示该列价格者排表尾。

三、名单来源释义

  • 名单怎么形成：候选服务来自维护者对公开渠道的持续观察与官网逐个查访；进入名单的唯一门槛是下面的收录标准，不存在付费入选；
  • 收录标准：有可访问官网、公开价格或明确免费规则；官网主体与联系方式可辨识。同类导航站也可收录，但会单独标明类型，不与卖 API 的服务混同；
  • 不收录：成品号、接码、账号租赁、反代等账号类商品——这类交易的风险无法靠信息核实消除，不在本站范围内；
  • 分类释义：「运营类型」（中转 / 聚合 / 导航站）按服务商在官网的自我定位归类；「模型家族」（Claude / GPT / Gemini / DeepSeek / Grok / 国产模型 / 其他）按其已核实的厂商名单归组。两者都是本站的编辑分类，不是服务商的官方定性；
  • 收录 ≠ 推荐：出现在名单里只表示「官网可核实地存在并符合收录标准」。带「推荐」标记的是编辑基于公开信息的主观选择，逐条附理由；带「商业合作」标记的按第五部分规则单独呈现（目前无在投条目）；
  • 价格口径：单价统一为「每 1M tokens 的输入 / 输出 / 缓存读价」，保留原始币种；不同币种不自动换算混排，避免汇率口径污染比价结论。

编辑精选（「推荐」标记）评选标准

首页「编辑精选」与卡片上的「推荐」标记，是本站编辑基于公开核实信息作出的主观评选，不是付费排名。入选主要看四点：

  • 信息透明度：官网主体、价格与使用规则公开可查，不用暗价与隐藏收费；
  • 价格可核实性：核心模型的单价能在官网公开页面逐项复核，计价口径清楚；
  • 免费额度真实性：免费额度或免费模型确为现行政策，并能在官方页面证实；
  • 官网信息完整度：模型、支付、注册与状态等关键信息齐全，有持续维护的痕迹。

编辑评选不收费、不售卖、不接受付费入选，每条入选的理由都写在卡片「推荐」标记的悬停说明里，接受公开检验。它与付费广告位是两套完全分开的机制：广告位在目录首排独立分区、带「广告」角标（见第五部分与广告合作页），投放广告不会获得「推荐」标记，也不会改变编辑评选结果。

四、纠错通道

发现条目有误、价格已变、免费政策调整，或你是被收录方想申请修正 / 下架，请通过页末的联系邮箱告知我们，并尽量附上服务商官方页面链接。我们会按与新收录相同的标准复核：确认属实的更正会更新条目并记入其「核实记录」时间线；无法在官方页面确认的，按「待核实」处理并回复说明。

投稿新服务请用投稿收录页的结构化表单（最终仍经邮箱送达），附官网地址即可；投稿只是递交线索，进不进名单要看我们能否在它的官方页面逐项核对到，流程见投稿页说明。
