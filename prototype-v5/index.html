计费口径（与网关现行规则一致）

  • 按实际输入/输出 token 计量；请求失败不计费。
  • 每笔调用先预扣、后按实际用量结算，多退少补——收据里能逐笔看到。
  • 用户总额度与每把 Key 的上限互相独立，任一耗尽返回 403 并给出诊断。

开发者

三步完成第一次调用，每一步都能验证。

1 · 拿到测试 Key

在控制台创建 API Key（测试阶段仅限管理员发放）。Key 只显示一次，请妥善保存。

2 · 发起调用

接口兼容 OpenAI 格式，把 base_url 换成网关地址即可。

3 · 核对收据

在控制台日志里核对这一笔的预扣、结算与退回，和你的预期对上再继续。

关于 Aivaro

Aivaro 是一个 AI API 网关与多模型使用平台，目前处于测试阶段。这个页面是原来的品牌介绍——现在它退到辅助位置，产品的主角是对话。

我们的两条产品原则

  • 每次调用，都有收据。预扣多少、结算多少、退回多少，逐笔可查；失败不计费不是口号，是可以核对的账目。
  • 每次失败，都有诊断。错误会说明问题出在网关、上游还是请求本身，并给出下一步，而不是只扔一个状态码。
