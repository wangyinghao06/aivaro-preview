Aivaro 是 OpenAI 兼容的 AI API 网关：换一个 Base URL 就能调用模型。我们的不同之处是把账算到每一次请求 — 预扣多少、结算多少、退回多少，逐笔可查；请求失败时，给你的不是错误码，而是一张说人话的诊断卡。

为什么是 Aivaro

逐笔收据

每次调用生成一张收据：模型、输入/输出 Token、预扣、结算、差额退回，一笔一笔对得上。费用不再是一团黑箱总数。

失败诊断卡

401、403、429、500 不再让人猜：诊断卡用一句话说明发生了什么、问题在哪一侧、下一步点哪里，并附可复制的诊断信息。

模型真实状态

模型中心只标真实状态：可用、限额、未接入，写得清清楚楚。没有接通的模型，绝不出现在「可用」列表里。

Key 自主管理

按用途创建独立 Key、各自设额度上限、随时撤销。泄露一个 Key，不影响其他业务。

怎么选模型？

测试阶段只有一个模型，其实不用选。等模型变多时，这里会提供：按任务找模型（写代码/长文档/快速问答）、同题对比试驾（同一问题并排问两个模型，比较回答、耗时与费用）。原型阶段可在对话页用模型选择器预览交互。

计量方式（与现网一致）

按 Token 计量

按上游返回的实际用量记录；每次调用生成收据，预扣与结算的差额自动退回。

失败不计费

请求失败、超时或被上游拒绝时不扣减额度，已预扣的在结算时退回。

额度上限

用户总额度与单个 Key 上限相互独立，任一耗尽返回 403 并给出诊断卡。

开发者中心

目标：新用户在几分钟内完成第一次成功调用；失败时，先在这里自检，再去提问。
